## Что отличает AMSignal

- **Согласованный анализ откликов.** Несколько откликов относительно общей опоры на одном участке записи. Несколько опорных каналов можно усреднить перед расчётом.
- **Единый измерительный процесс.** Загрузка записи → обработка каналов → анализ → измерительная разметка → график для отчёта.
- **Переносимое рабочее окружение.** Приложение, локальные настройки и проекты с исходными отсчётами можно перенести на другой компьютер Windows.

Нажмите на изображение, чтобы открыть его крупно. В примере АЧХ две опоры **Reference A / Reference B** усредняются перед H1/Welch; для **Response A / Response B** строятся отдельные кривые на одном участке записи.

## Измерения и график для отчёта

![Три точки измерения, маркер и направляющие в AMSignal](docs/assets/screenshots/measurements-ru.png)

Ставьте точки на отсчётах, измеряйте координаты и интервалы, отмечайте события маркерами и добавляйте вертикальные и горизонтальные направляющие. Разметка сохраняется в проекте и включается в экспорт PNG.

## Остальные возможности

- Цифровые фильтры, индивидуальные множители и общая формула каналов.
- Выбор участка для FFT/АЧХ, имена, цвета и видимость каналов.
- Фигуры кривых для Ч/Б, светлая и тёмная темы, настраиваемые клавиши.
- Большие записи: автоматический выбор RAM или дискового пути; расчёты по исходным отсчётам.

[Все возможности с изображениями и примерами →](docs/FEATURES_RU.md)

## Скорость на практике

Пример GUI-замеров **v0.17.3**: реальная запись **1,024 ГБ**, 6 832 000 отсчётов × 8 каналов, Auto с размещением данных в RAM.

| Операция | Время |
| --- | ---: |
| Открытие записи | 33,22 с |
| Полный FFT одного исходного канала | 2,63 с |
| Первый H1 для семи откликов | 1,82 с |
| Повторный H1 с готовой подготовкой входа | 0,97 с |

Медианы трёх процессов: Windows 10, Ryzen 5 5600X, 32 GiB RAM; кэш ОС не очищался. H1: одна опора, L=2048, Hann, перекрытие 50%, удаление среднего. Это результаты указанной версии; время зависит от входа, обработки и ресурсов. Дисковый путь может быть значительно медленнее. [Методика и расход памяти →](docs/PERFORMANCE_RU.md)

## Начните работу

1. Скачайте GUI EXE из [последнего выпуска](https://github.com/almuleev/AMSignal/releases/latest) и запустите его из доступной для записи папки.
2. Откройте LabVIEW `.lvm`, табличный `.txt` / `.csv` или [демонстрационную запись](examples/README_RU.md).
3. Выполните анализ, сохраните проект `.AMSig` для продолжения работы и PNG для отчёта.

Установщик, LabVIEW и Qt не требуются. Для переноса скопируйте EXE, лежащий рядом `AMS.ini` и проекты. Роли FRF, метод и L сохраняйте дополнительно в CSV или описании опыта. [Быстрый старт](docs/QUICK_START_RU.md) · [Перенос окружения](docs/PORTABLE_RU.md).

Архивы GitHub **Source code** содержат исходники; CLI можно [собрать отдельно](docs/BUILD_RU.md).
