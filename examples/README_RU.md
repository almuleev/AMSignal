# Демонстрационная запись

[Проект](../README_RU.md) · [English](README.md) · [Быстрый старт](../docs/QUICK_START_RU.md)

[`demo-signals.txt`](demo-signals.txt) — табличная **синтетическая** запись с разделением табуляцией для знакомства с интерфейсом и воспроизведения сцен документации. В ней 32 768 отсчётов при 1024 Гц, от 0 до 31,9990234375 с, и четыре канала с условными единицами вольт:

| Канал | Назначение |
| --- | --- |
| `Reference A [V]` | Первая опора: широкополосный сигнал с 12 тонами и малой добавкой шума |
| `Reference B [V]` | Вторая синхронная опора того же возбуждения с независимой добавкой шума |
| `Response A [V]` | Выход модели второго порядка, собственная частота 32 Гц, коэффициент затухания 0,045 |
| `Response B [V]` | Выход модели второго порядка, собственная частота 75 Гц, коэффициент затухания 0,065 |

Модели отклика используют `H(s) = w0^2 / (s^2 + 2*zeta*w0*s + w0^2)`, `w0 = 2*pi*f0`, с билинейной дискретизацией при 1024 Гц. Начальные условия нулевые; перед выгружаемой последовательностью отбрасываются 4096 отсчётов прогрева. Вход — сумма 12 синусоид со случайными фиксированными фазами и равномерного шума `0.45*u`. Тоны: 12, 24, 39, 48, 61, 88, 103, 117, 136, 151, 173 и 192 Гц. Генератор Python `random.Random(1729)` сначала задаёт фазы, затем широкополосный шум. Две опоры получают независимые добавки `0.01*u` от `random.Random(1730)`. Вход обеих моделей отклика — арифметическое среднее этих опор. Это два синхронных измерения общего возбуждения, а не два независимых входа MIMO. Полный воспроизводимый рецепт — [`generate_demo.py`](generate_demo.py), без внешних библиотек; команда `python examples/generate_demo.py` пересоздаёт только этот TXT.

Пример не является физическим экспериментом, эталонным бенчмарком или численной аттестацией программы. Конечные окна, уровень возбуждения и утечки влияют на оценённые кривые; пики FRF не обязаны точно совпадать с собственными частотами непрерывных моделей.

## Повторить сцены

1. Откройте TXT в AMSignal, покажите все четыре канала.
2. Для временного графика задайте видимый диапазон 1–1,5 с. Оставьте **Анализ → Вся запись**.
3. Переключитесь в спектр; используйте вид 0–210 Гц для просмотра тонов.
4. В режиме АЧХ назначьте `Reference A` и `Reference B` опорами, оба Response — откликами, выберите H1 Welch и `L = 2048`, выключите сглаживание, затем рассчитайте. Для всей записи получатся 31 сегмент и шаг частоты 0,5 Гц. Задайте частотный вид 5–210 Гц. Единицы в квадратных скобках убираются из отображаемых имён.
5. Переключите язык или тему для соответствующего варианта галереи.
