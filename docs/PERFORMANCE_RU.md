# Скорость и ресурсы

[Документация](README_RU.md) · [English](PERFORMANCE_EN.md)

Это пользовательская выдержка из завершённой серии сравнения **16 октября 2026 года**. Она описывает **v0.17.3**, а не результаты нового испытания последнего выпуска. Полный сводный отчёт и исходные протоколы хранятся отдельно; расположение для сопровождающих — в [справочнике внешних материалов](development/EXTERNAL_MATERIALS.md).

## Реальная запись 1,024 ГБ

Вход: **1 024 104 009 байт**, 6 832 000 отсчётов, восемь каналов. GUI в Auto, данные помещаются в RAM. Таблица — медианы трёх отдельных процессов, секунды.

| Операция | v0.17.3 |
| --- | ---: |
| Открытие в цепочке анализа | 33,2168 |
| Первый полный FFT одного исходного канала | 2,6251 |
| Новый полный FFT одного исходного канала | 2,6555 |
| Первый H1 для семи исходных откликов | 1,8154 |
| Повторный H1 | 0,9736 |
| Первый FFT с обработкой | 3,4361 |
| Первый H1 с обработкой | 2,1636 |

FFT использует все 6 832 000 отсчётов одного канала. H1: одна опора, семь откликов, `L=2048`, периодический Hann, перекрытие 50%, удаление среднего. Повторный H1 выполняет расчёт с повторным использованием подготовки входа; это не выдача готового FFT из кэша.

Фильтр в обработанных сценариях — НЧ Баттерворта, граница 0,2 частоты Найквиста, все восемь каналов. Пик рабочего набора **всей цепочки** — 2545,95 MiB, пик commit — 2663,25 MiB; эти пики не относятся к одному FFT.

## Условия и воспроизводимость

- Windows 10 Pro 10.0.19045, AMD Ryzen 5 5600X, 6 ядер / 12 логических, 32 GiB RAM, профиль Power saver.
- GCC 14.2.0, C++17, `-O2 -static`, без fast-math. Чистый тег v0.17.3, коммит `0a0e23e40df72d244ae8fe3df0f850b315f0b350`.
- Три процесса на версию и файл. Версии запускались последовательно с циклическим изменением порядка, сборка завершалась до замеров. Кэш Windows не очищался: «новый индекс» не означает холодное чтение диска.
- Стенд вызывает штатные загрузчик, worker и GDI-отрисовку в bitmap; это время программного пути, без задержек видимого окна, монитора и действий пользователя. Геометрия анализа: bitmap 1100×700 / plot 1000×590; навигации: bitmap 1000×650 / plot 880×530.
- SHA-256 входа: `302c016159448f72713bf31e82782429604a449700be53b156c70873d8852465`.
- Источник цифр: разделы «GUI Auto: анализ и обработка» и «Открытие, фильтр и навигация отдельного свежего процесса» единого отчёта; первичные файлы `gui.jsonl`, `navigation.jsonl`, `manifest.json` серии 2026-10-16.

## Как понимать цифры

Время зависит от формата, числа каналов, N, участка, L, обработки, памяти, диска и готовности кэша. Больший файл или другой компьютер не обязаны показывать ту же скорость. Приведённые Auto-замеры нельзя переносить на дисковый FFT.

Небольшой участок сокращает объём анализа, если он выбран явно через **Анализ**. Масштабирование графика само по себе не уменьшает вход FFT/FRF. Сравнивайте полный рабочий сценарий и расход ресурсов, а не только готовую отрисовку или отдельное математическое ядро.
