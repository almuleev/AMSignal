## Русский

### Исправлено

- **Автомасштабирование** в режиме АЧХ теперь одновременно возвращает автоматические диапазоны Y для графика КД и нижнего графика **«Ср. опора»**.
- Если вручную изменена только шкала средней опоры, кнопка и пункт меню автомасштаба корректно возвращают обе шкалы в Auto, а не переводят их в ручной режим.
- Перетаскивание нижнего графика средней опоры изменяет только его вертикальный диапазон Y.
- Состояние кнопки и пункта меню автомасштаба теперь отражает режим обеих вертикальных шкал.

### Управление

- `Ctrl` + колесо над нижним графиком — масштабирование его Y вокруг указателя.
- `Alt` + колесо или перетаскивание нижнего графика — перемещение только его Y-диапазона.
- Обычная навигация частоты по X по-прежнему синхронно действует на КД и среднюю опору.

### Проверка

- Добавлены GUI-регрессии для сохранения общей X-шкалы при переносе опоры и для восстановления Auto после ручного изменения только её шкалы.
- Выполнены 333 GUI-регрессионных проверки, полные сборки CLI и GUI.

## English

### Fixed

- **Auto-scale** in FRF now restores automatic Y ranges for both the KD graph and the lower **averaged Reference** graph.
- If only the averaged-Reference scale was adjusted manually, the Auto-scale button and menu item correctly restore both ranges instead of switching them to manual mode.
- Dragging the lower averaged-Reference graph changes only its vertical Y range.
- The Auto-scale button and menu state now reflect both vertical scales.

### Controls

- `Ctrl` + mouse wheel over the lower graph zooms its Y range around the pointer.
- `Alt` + mouse wheel or dragging the lower graph pans only its Y range.
- Regular X-frequency navigation remains synchronized between KD and averaged Reference.

### Verification

- Added GUI regressions for preserving the shared X view while dragging Reference and restoring Auto after adjusting only its scale.
- Ran 333 GUI regression checks and full CLI and GUI builds.
