# v0.17.8-cpu.2

## Русский

Проект `.AMSig` сохраняет условия повторного расчёта АЧХ. Раньше после
повторного открытия приходилось заново назначать опоры, отклики и метод.
Теперь эти параметры восстанавливаются вместе с поддерживаемыми настройками.

### Изменения относительно v0.17.8-cpu.1

- Новая секция `[frf_settings]`: роли опор/откликов, H1/Direct, запрошенный L
  (включая Auto), удаление среднего, порог опоры и экранное сглаживание.
- Сохранение границ частотного диапазона и амплитудной шкалы АЧХ, ручного
  или автоматического масштаба. Существующий общий участок анализа,
  исходные данные, формулы, фильтры и настройки обработки не заменены.
- При экспорте подмножества каналов роли перенумеровываются относительно
  экспортированных столбцов. Ошибочные индексы, дубли и пересечение ролей
  не применяются. Некорректные параметры отклоняются в пределах проверки импорта.
- Метаданные проектов, табличного экспорта и CSV АЧХ содержат
  `application_version` и `exported_utc`. CSV АЧХ дополнительно сохраняет
  `segment_length_requested` и `display_smoothing_octaves`. Основные
  параметры фактического расчёта уже присутствовали и сохранены.
- Добавлен GUI-сценарий сохранения/открытия/пересчёта: несколько опор,
  выбранный участок, H1, Direct/Auto, сглаживание, границы отображения,
  подмножество каналов, невалидные роли и старые метаданные.
- Обновлены инструкции переноса окружения RU/EN и контракты метаданных.

### Унаследованные изменения и границы

Основа — коммит `d43a5ce`, тег `v0.17.8-cpu.1`: параллельный разбор
текстовых записей и распределение FRF-преобразований по парам сегмент/канал.
Этот коммит уже содержит поправку амплитуды опоры на чётной границе
Найквиста и её численные регрессии. Исправление не меняет формулу H;
оно не добавляется повторно этим коммитом. Порядок накопления спектров
и управление CPU-пулом новыми правками метаданных не меняются.

Старые проекты читаются, но отсутствовавшие настройки АЧХ нужно назначить
вручную. Переход в режим АЧХ запускает повторный расчёт; восстановление
кэша результата и последнего режима интерфейса не заявлено. Сглаживание
является настройкой отображения и не заменяет исходный комплексный H.
Паспорт экспорта не подтверждает калибровки, приёмку объекта или внедрение.

### Проверки

- CLI и GUI успешно собраны из рабочего дерева с этими изменениями.
- Полный пересобранный набор ядра: **1405 утверждений, 0 ошибок**.
- Пересобранный полный GUI-набор: **7193 утверждения, 0 ошибок**.
- Затронутый набор `--frf`: **296 утверждений, 0 ошибок**.
- В GUI-тесте после открытия проекта совпадают сетка, маски, L/K/N;
  комплексный H на допустимых частотах отличается менее чем на `10^-12`.
  Это синтетический пример, а не погрешность стендового измерения.
- `git diff --check` пройден. Изменения документации после успешных
  прогонов не требуют повторного запуска тех же тестов.

Числа относятся к утверждениям тестов, а не независимым сценариям.
Новых замеров CPU/производительности, сравнения с FAMOS, испытания на
другом компьютере и лабораторной приёмки не проводилось. Старые результаты
не переименованы в результаты новой версии. Это локальный аннотированный
тег исходников; публикация, отправка в remote и новый комплект EXE не выполнялись.

## English

AMSig projects now preserve FRF recalculation settings. Reopening a new
project restores reference/response roles, H1/Direct, requested segment
length including Auto, mean removal, reference threshold, display smoothing
and FRF view bounds. Existing source samples, shared analysis interval,
formulas, filters and processing settings remain supported.

### Changes since v0.17.8-cpu.1

- Added `[frf_settings]` serialization and restoration. Channel subsets use
  role indices remapped to exported columns. Invalid, duplicate or overlapping
  roles are rejected; imported parameters are validated.
- Project/tabular and FRF CSV metadata now include `application_version`
  and `exported_utc`. FRF CSV also includes `segment_length_requested` and
  `display_smoothing_octaves`, alongside existing actual calculation metadata.
- Added GUI roundtrip coverage for multiple references, selected intervals,
  H1, Direct/Auto, smoothing, view bounds, channel subsets, invalid roles
  and legacy metadata. Updated bilingual portability instructions and contracts.

### Inherited changes and limitations

Built on `d43a5ce` / `v0.17.8-cpu.1`, retaining parallel text parsing and
segment/channel FRF scheduling. The parent already contains the even-length
Nyquist reference-amplitude correction and numerical regressions; this commit
does not apply it again. The correction leaves the transfer-function formula
unchanged. New metadata code does not change CPU-pool scheduling or spectral
accumulation order.

Older projects remain readable but cannot recover settings absent from their
files. Enter FRF mode to recalculate; result-cache or last-mode restoration
is not claimed. Display smoothing is separate from raw complex H. Export
provenance does not establish sensor calibration or laboratory acceptance.

### Validation

CLI and GUI builds succeeded. Rebuilt full core suite: **1405 assertions,
zero failures**; rebuilt full GUI suite: **7193 assertions, zero failures**;
FRF subset: **296 assertions, zero failures**. The synthetic GUI roundtrip
preserves frequency grids, masks and L/K/N; valid complex H agrees within
`10^-12`. This tolerance does not describe physical measurement accuracy.
`git diff --check` passed. Successful runs were reused after documentation-only
edits; assertion counts do not denote independent scenarios.

No new performance/FAMOS benchmark, second-machine validation or laboratory
acceptance was performed. Historical measurements remain tied to their original
versions. This is a local annotated source tag, with no remote push, publication
or newly versioned executable package.
