## Русский

AMSignal v0.13.0 — релиз с полным переименованием приложения.

- Приложение, заголовки окон, справка, LVM-экспорт, bat-лаунчеры, сборочные сценарии и документация теперь используют имя **AMSignal**.
- Локальный файл настроек переименован в **AMS.ini**.
- GUI-артефакт выпуска получил единый формат **AMSignal-0.13.0-x64.exe**: новое имя, архитектура x64 и номер без префикса `v`.
- Включены актуальные улучшения режима АЧХ: встроенный выбор опор и откликов, общие с Time/FFT аннотации, сглаживание только для отображения, диагностическая coherence и навигация без мерцания.

## English

AMSignal v0.13.0 is the full application rebranding release.

- The application, window titles, help, LVM export, batch launchers, build scripts, and documentation now use the **AMSignal** name.
- The local settings file has been renamed to **AMS.ini**.
- The GUI release asset now follows the unified **AMSignal-0.13.0-x64.exe** format: new brand, x64 architecture, and a version number without the `v` prefix.
- It includes the current FRF improvements: embedded reference/response selection, shared Time/FFT annotations, display-only smoothing, diagnostic coherence, and flicker-free navigation.
