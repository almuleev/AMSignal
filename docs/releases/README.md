# Release history / История выпусков

[Documentation](../README.md) · [Документация](../README_RU.md)

Use [GitHub Releases](https://github.com/almuleev/AMSignal/releases) for published downloads and [CHANGELOG.md](../../CHANGELOG.md) for the chronological change history.

Готовая программа скачивается из [GitHub Releases](https://github.com/almuleev/AMSignal/releases); хронология изменений — в [CHANGELOG.md](../../CHANGELOG.md).

Files named `*-github.md` are the source texts for GitHub release pages. Other version-named files preserve the detailed release notes. They describe their own version, including the original measurements and limitations; use the current documentation for present-day instructions.

Файлы `*-github.md` — исходные тексты страниц выпусков GitHub. Остальные файлы с номерами версий сохраняют подробные журналы. Их ограничения и замеры относятся к соответствующему выпуску; актуальные инструкции находятся в текущей документации.
