# AMSignal v0.17.4 — 2026-10-16

## Русский

Полный состав изменений после v0.17.3: уточнение правой панели и удаление
подтверждённого неиспользуемого кода с проверкой сохранности поведения.

### Видимый диапазон только в «Каналах»

- Общий блок «Видимый диапазон» расположен только снизу вкладки «Каналы»
  во всех режимах: Сигнал, FFT и АЧХ. На вкладках «Точки» и «Фильтр» он скрыт.
- Высота содержимого «Точек» заканчивается кнопками создания/удаления групп.
  Резерв под скрытый диапазон удалён: снизу нет пустого места и лишней прокрутки.
- Нижний блок «Каналов» сохраняет поля, кнопку, единицы и прежнюю проверку
  границ. Сигнал использует исходное время в секундах, FFT/АЧХ — частоту в Гц.
  Изменение просмотра не меняет участок анализа, расчёты или историю разметки.
- Регрессия проверяет скрытие всех шести контролов в «Точках» после прокрутки
  и обновления панели во всех трёх режимах. Проверки ввода диапазона перенесены
  на «Каналы», включая FFT и готовую АЧХ; локализация и блокировка pending сохранены.

### Удалены 20 неиспользуемых элементов

- Четыре функции подписей старой панели индивидуальных формул:
  side_formula_apply_selected_text, side_formula_apply_visible_text,
  side_formula_reset_selected_text и side_formula_reset_all_text.
- Пять никогда не создававшихся оконных полей App: side_formula_edit,
  side_formula_apply_selected, side_formula_apply_visible,
  side_formula_reset_selected и side_formula_reset_all. Удалены ветки обновления,
  включения и переименования этих всегда-null контролов.
- Два нечитавшихся поля App::cached_scan_start/cached_scan_end вместе с записями.
  Рабочие границы источника, ScanIndex, cached_scan_path, valid и index сохранены.
- Три невостребованных поля AsyncScanResult: index_seconds, metadata_seconds,
  prepare_seconds; три обслуживавших их локальных таймера metadata_started,
  prepare_started, index_started. Измерения не имели потребителя; чтение,
  подготовка данных, проверка версии файла и публикация результата сохранены.
- Никогда не заполнявшийся App::toolbar_seps, его очистка и пустой цикл отрисовки.
  Убраны также создание, выбор и освобождение пера вокруг этого пустого цикла.
- Неиспользуемое поле ExportPromptState::intro.
- Неиспользуемый цвет Theme::btn_pressed и его позиции в обеих инициализациях
  тем. Значения остальных цветов, включая playhead и marker_color, сохранены.

Всего: четыре функции, 13 полей структур и три локальные переменные.
Очистка затрагивает 12 производственных файлов C++: 77 строк удалены,
одна добавлена, чистое сокращение — 76 строк. Изменение расположения диапазона
и документация считаются отдельно от этих 76 строк.

### Совместимость и сохранённые пути

- В оставленном старом WM_COMMAND обращение к side_formula_edit заменено
  на nullptr: read_formula_edit возвращает прежнюю ошибку отсутствующего поля.
  Команды не перенумерованы; старые обработчики не удалялись в рамках очистки.
- Зарезервированные LowLabel/Low/HighLabel/High и остальные ID сохранены:
  удаление элементов enum могло бы сдвинуть последующие номера.
- Сохранены девять API, используемых тестами/бенчмарком: DiskCache::used_bytes,
  DiskCache::entry_count, analyze_frf, analyze_frf_batch, set_frf_channels,
  frf_reference_y_max, configure_recording_disk_cache,
  RecordingOverview::level_count и RecordingSource::from_memory.
- Рабочие коэффициенты каналов, общая формула и импорт старых формул сохранены.
  Parser, FFT, FRF/H1/Welch/coherence, фильтрация, кэширование, исходные данные,
  настройки, формат проекта и экспорт не переписывались.
- Карта модулей и инструкции обновлены; ранее внесённые правки панели и тестов
  сохранены. Зафиксирован текущий промежуточный статус внешнего сравнения
  rc.3/v0.17.2/v0.17.3: 92 группы fingerprints совпали, открытие 10 GB ещё идёт.
  Эти результаты относятся к прежним тегам, а не к измерениям v0.17.4.

### Проверка перед созданием тега

- Удаление сначала проверено в отдельном снимке текущих исходников:
  полный набор ядра — 1357 проверок, 0 ошибок; GUI до/после — по 8619 проверок.
- В рабочем checkout после применения выполнены обе полные штатные сборки
  build_cli.ps1/build_gui.ps1 и build_gui.ps1 -Test: все 8619 GUI-проверок успешны.
- Все 146 .cpp/.hpp программы и тестов совпали с проверенным снимком
  после нормализации окончаний строк. Ядро повторно не запускалось без новых изменений.
- Все 11 PNG до/после совпали побайтово по SHA-256: легенда, тёмные подписи осей,
  графики АЧХ с опорой и без неё, H1, несколько откликов, крайние частотные деления,
  панель АЧХ и обзор в светлой/тёмной теме.
- CLI успешно прочитал test.lvm и выполнил FFT/CSV: 10000 отсчётов,
  5001 частотный бин, три канала. Проверки diff и применимости патча прошли.
- Состав тестов не упрощался ради очистки; тесты диапазона соответствуют новому
  размещению блока только в «Каналах».

После создания аннотированного тега штатные CLI/GUI и GUI-регрессия выполняются
из чистого checkout v0.17.4; проверяются git describe, версия ресурсов обеих
программ и SHA-256. Локальные логи и протокол предварительной проверки находятся
в .build/dead-code-removal-check-20261016, который не входит в Git.

### Границы результата

Замеров скорости до/после очистки не проводилось. Удалены лишние операции,
но численный выигрыш и универсальное отсутствие замедлений не заявляются.
Новые испытания больших записей, физического ПК 8 GiB и FAMOS не выполнялись;
исторические disk-регрессии не объявляются исправленными. Текущая область
испытаний — до 10000000000 байт включительно; новые 20 GB испытания исключены.
Это область проверок, а не искусственный предел открытия файлов.

Тег создаётся локально, старые теги/EXE/пакеты не заменяются. Локальные EXE
не подписаны; создание тега не означает публикацию GitHub Release или отправку
изменений на сервер.

## English

Complete changes since v0.17.3: a clearer side panel and removal of confirmed
unused code, with behavior-preservation checks.

### Visible range belongs to Channels

- The shared Visible range block appears only at the bottom of Channels in
  Signal, FFT and FRF. Points and Filter hide the entire block.
- Points content ends after the group creation/deletion buttons. Removing
  the unused range reservation eliminates the blank space and extra scrolling.
- Channels retains the existing fields, button, units and boundary validation:
  original seconds for Signal and hertz for FFT/FRF. View changes preserve the
  analysis interval, computed results and annotation history.
- Regression coverage checks all six hidden controls after scrolling and panel
  refresh in all three modes. Range-entry checks now use Channels, including
  FFT and calculated FRF; localization and pending-state protection are retained.

### Twenty unused elements removed

- Four old per-channel formula label functions: side_formula_apply_selected_text,
  side_formula_apply_visible_text, side_formula_reset_selected_text and
  side_formula_reset_all_text.
- Five App window fields whose controls were never created: side_formula_edit,
  side_formula_apply_selected, side_formula_apply_visible,
  side_formula_reset_selected and side_formula_reset_all, together with the
  unreachable update, enable and rename branches for these always-null handles.
- The unread App::cached_scan_start/cached_scan_end fields and their assignments.
  Actual source bounds, ScanIndex, cached_scan_path, valid and index are retained.
- Three unconsumed AsyncScanResult timing fields: index_seconds, metadata_seconds
  and prepare_seconds; their three local timers metadata_started,
  prepare_started and index_started. Source reading, preparation, source-version
  checks and result publication are retained.
- The never-populated App::toolbar_seps list, its clear operation and empty
  rendering loop, including the surrounding pen creation/selection/destruction.
- The unused ExportPromptState::intro field.
- The unused Theme::btn_pressed color and its entries in both positional theme
  initializers. Other colors, including playhead and marker_color, retain their values.

Total: four functions, thirteen structure fields and three local variables.
The cleanup changes twelve production C++ files: 77 lines removed and one added,
for a net reduction of 76 lines. Panel placement and documentation changes are
separate from this cleanup count.

### Compatibility and retained paths

- The preserved legacy WM_COMMAND passes nullptr instead of side_formula_edit.
  read_formula_edit returns the same missing-field error. Commands retain their
  numbers; legacy handlers were not removed as part of this cleanup.
- Reserved LowLabel/Low/HighLabel/High and other IDs are retained; deleting enum
  entries could otherwise shift the following command numbers.
- Nine APIs used by tests/benchmarks are retained: DiskCache::used_bytes,
  DiskCache::entry_count, analyze_frf, analyze_frf_batch, set_frf_channels,
  frf_reference_y_max, configure_recording_disk_cache,
  RecordingOverview::level_count and RecordingSource::from_memory.
- Active channel coefficients, the shared formula and legacy formula import
  remain available. Parser, FFT, FRF/H1/Welch/coherence, filtering, caches,
  original data, settings, project format and exports were not rewritten.
- Architecture and working instructions are updated, preserving the existing
  panel/test edits. Documentation records the intermediate external comparison
  of rc.3/v0.17.2/v0.17.3: 92 fingerprint groups matched; 10 GB opening work is
  still in progress. These results concern those earlier tags, not v0.17.4 timings.

### Validation before tagging

- The removal was first tested in an isolated snapshot of the current sources:
  1357 core checks with zero failures, and 8619 GUI checks both before and after.
- Both complete standard build_cli.ps1/build_gui.ps1 builds and
  build_gui.ps1 -Test succeeded in the working checkout after applying the cleanup;
  all 8619 GUI checks passed.
- All 146 program/test .cpp/.hpp files matched the validated snapshot after
  line-ending normalization. Core tests were not repeated without new changes.
- All eleven before/after PNG files matched byte for byte by SHA-256: legends,
  dark axis captions, FRF with/without the reference plot, H1, multiple responses,
  edge frequency ticks, the FRF panel and light/dark overview rendering.
- CLI successfully parsed test.lvm and performed FFT/CSV export: 10000 samples,
  5001 frequency bins and three channels. Diff and patch-applicability checks passed.
- Tests were not weakened for the cleanup; range tests reflect the new
  Channels-only placement.

After creating the annotated tag, standard CLI/GUI builds and GUI regression
are run from a clean v0.17.4 checkout, checking git describe, executable version
resources and SHA-256. Preliminary local logs and the audit protocol are in
.build/dead-code-removal-check-20261016, which is not tracked in Git.

### Limits of the result

No before/after cleanup performance measurements were taken. Redundant work was
removed, but no numerical speedup or universal no-slowdown guarantee is claimed.
No new large-recording, physical 8 GiB PC or FAMOS tests were run, and historical
disk regressions are not claimed fixed. Current testing scope is up to and
including 10000000000 bytes; new 20 GB tests are excluded. This is test scope,
not an artificial file-opening limit.

The tag is local. Older tags, executables and packages are not replaced.
Local executables are unsigned. Creating the tag does not publish a GitHub
Release or push changes to a remote server.
