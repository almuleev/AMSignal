## Русский

Выпуск `v0.16.1` завершает доработку ручной разметки графиков в режимах **Время**, **Спектр** и **АЧХ**. Основное внимание уделено предсказуемому созданию, выбору, переносу и удалению измерительных точек, маркеров и направляющих, а также корректной работе Snap.

### Исправлено

- Горизонтальные направляющие теперь работают со Snap так же, как вертикальные:
  - при постановке они получают значение Y ближайшей отображаемой кривой;
  - при перетаскивании также привязываются к актуальному значению Y;
  - в режиме АЧХ используется именно сглаженная кривая, показанная на экране.

- Исправлено удаление выбранных объектов:
  - `Delete` и `Backspace` удаляют выбранную точку, маркер или направляющую;
  - удаление работает даже после редактирования поля в правой панели: щелчок по графику возвращает ему клавиатурный фокус;
  - при включённой блокировке разметки удаление, как и прежде, запрещено.

- После удаления последней точки из группы группа сразу исчезает из списка групп. Undo возвращает одновременно и точку, и её группу; Redo снова удаляет их вместе.

- Устранено наложение текста при совпадении вертикальной линии и маркера:
  - значение направляющей и номер маркера выводятся по разные стороны линии;
  - у левого края графика подписи автоматически разводятся без перекрытия.

### Доработано

- В режиме **Курсор** точка, маркер или направляющая выбираются щелчком и выделяются акцентной рамкой.

- Перенос существующего объекта выполняется в режиме **Курсор**. Он сохраняется как одно действие Undo/Redo.

- В активных инструментах **Точки**, **Маркер** и **Линия**:
  - короткий щелчок создаёт объект;
  - перетаскивание после смещения минимум на 4 пикселя панорамирует график;
  - активный инструмент имеет приоритет над выбором уже существующего объекта, поэтому разметку можно добавлять поверх других объектов.

- Убрано скрытое действие правой кнопки мыши: ПКМ больше не очищает точки или другую разметку.

- Исключены нежелательные дубликаты:
  - в одной группе нельзя создать вторую точку с теми же X/Y;
  - в текущем режиме нельзя повторно создать маркер в той же позиции;
  - нельзя повторно создать направляющую того же типа с тем же значением;
  - точки разных групп по-прежнему могут находиться в одной координате.

- Маркер теперь всегда отображает:
  - видимую точку в своей координате;
  - вертикальную направляющую X;
  - горизонтальную направляющую Y.

  При включённом Snap точка маркера использует цвет выбранного канала, без Snap — собственный цвет маркера.

- Пункт меню **Справка → О программе** переименован в **Справка → Начальный экран**. Английский вариант — **Help → Start screen**.

## English

`v0.16.1` completes the latest annotation-workflow improvements across **Time**, **Spectrum**, and **FRF** views. The release focuses on predictable creation, selection, dragging, and deletion of measurement points, markers, and guides, together with correct Snap behavior.

### Fixed

- Horizontal guides now honor Snap in the same way as vertical guides:
  - when created, they use the Y value of the nearest displayed curve;
  - when dragged, they continue to snap to the current curve Y value;
  - in FRF, snapping uses the smoothed curve currently shown on screen.

- Selected-object deletion is fixed:
  - `Delete` and `Backspace` remove the selected point, marker, or guide;
  - deletion works even after editing a right-side-panel field, because a graph click restores keyboard focus to the graph;
  - annotation locking continues to prevent deletion.

- When the final point in a group is removed, the empty group disappears from the group list immediately. Undo restores both the point and its group; Redo removes both again.

- Fixed label overlap when a vertical guide and marker share the same X position:
  - the guide value and marker label are drawn on opposite sides of the line;
  - near the left plot edge, labels are repositioned to remain readable without overlap.

### Improved

- In **Cursor** mode, a point, marker, or guide can be selected with a click and is shown with an accent outline.

- Existing objects are dragged in **Cursor** mode. Each completed move is recorded as one Undo/Redo action.

- With the **Points**, **Marker**, or **Line** tool active:
  - a short click creates an object;
  - dragging after at least four pixels of movement pans the graph;
  - the active placement tool takes priority over existing annotations, allowing objects to be placed over other annotations.

- Right click no longer performs an implicit annotation or point clear.

- Unwanted duplicates are prevented:
  - a point group cannot contain two points with identical X/Y coordinates;
  - the current mode cannot contain duplicate markers at the same position;
  - duplicate guides with the same orientation and value are not created;
  - points from different groups may still occupy the same coordinate.

- Every marker now always displays:
  - a visible point at its position;
  - a vertical X guide;
  - a horizontal Y guide.

  When Snap is enabled, the marker point uses the snapped channel color; otherwise it uses the marker color.

- The **Help → About** menu item has been renamed to **Help → Start screen**. The Russian interface uses **Справка → Начальный экран**.

### Documentation

Updated project documentation includes:

- `AGENTS.md`;
- `docs/ARCHITECTURE.md`;
- `CHANGELOG.md`;
- the Russian user manual in Markdown and Word formats.

The manual now reflects version `0.16.1`, current mode labels, Cursor-mode interaction, Snap behavior, Delete/Backspace removal, point-group cleanup, guide and marker behavior, right-click behavior, and the renamed start screen.
