# AMSignal v0.17.6 — 2026-10-17

## Русский

Документационный выпуск: обновлены главная страница, пользовательские инструкции и оформление проекта на GitHub. Исходники приложения, численного ядра и тестов не изменены относительно v0.17.5. GUI и CLI пересобраны из чистого помеченного коммита с версией 0.17.6.

### Главная страница и инструкции

- Главная страница показывает три режима: Сигнал, Спектр и АЧХ. Отдельно представлен пример измерительной разметки и кратко описаны отличия программы.
- Пользовательские страницы RU/EN имеют одинаковое содержание: быстрый старт, возможности, анализ и ограничения, галерея, перенос окружения, сборка/CLI и полное руководство.
- Добавлены пояснения фильтров, точек, маркеров, направляющих, участка анализа, фигур для Ч/Б, PNG, имён каналов, множителей и общей формулы.
- Описан перенос EXE, AMS.ini и проектов AMSig. Проект содержит исходные отсчёты; роли FRF, метод и L дополнительно сохраняются в CSV или протоколе опыта.
- Страница производительности использует сохранённые замеры v0.17.3 с исходными условиями; они не обозначаются как новое испытание v0.17.6.
- Технические справочники и история отделены от пользовательских инструкций. Старое руководство сохранено как историческое.

### Изображения и демонстрационная запись

- Обновлена выбранная пользователем обложка.
- Изображения интерфейса получены нативной отрисовкой приложения без указателя мыши; PNG графиков сохранены штатным экспортом. Кривые не ретушировались и не генерировались ИИ.
- Синтетическая запись: 32 768 отсчётов при 1024 Гц, две опоры и два отклика, широкополосное возбуждение и 12 тонов. Генератор включён в исходники.
- Пример АЧХ показывает два отклика относительно арифметического среднего двух опор. H1/Welch: L=2048, K=31, Hann, перекрытие 50%, шаг 0,5 Гц. Это общая усреднённая опора, не MIMO-отождествление независимых входов.
- Пример измерений содержит три точки, маркер и вертикальную/горизонтальную направляющие. Отдельные кадры показывают фильтр, участок, обработку каналов и фигуры для Ч/Б.

### Оформление GitHub

- Обновлены описание и темы репозитория, добавлены ссылки на документацию.

- Technical references and historical material are separated from user guides. The earlier manual is retained as history.

### Images and demonstration recording

- Updated the user-selected cover.
- Interface images use native application rendering without a mouse pointer; graph PNGs use the production exporter. Curves are neither retouched nor AI-generated.
- Synthetic recording: 32,768 samples at 1024 Hz, two references, two responses, broadband excitation and 12 tones. The generator is included in the sources.
- The FRF example shows two responses against the arithmetic sample mean of two references. H1/Welch: L=2048, K=31, Hann, 50% overlap and 0.5 Hz spacing. This is an averaged shared reference, not independent multiple-input MIMO identification.
- Measurement images contain three points, a marker and vertical/horizontal guides. Other scenes illustrate filtering, interval selection, channel processing and grayscale curve symbols.

### GitHub presentation

- Refreshed repository description, topics and documentation links.
- Issue and feature forms include RU/EN guidance; bug reports request the version and relevant analysis settings.
- Selected historical release titles match their original tags; full previous notes are retained below download links and short RU/EN summaries.
- Existing tags and assets are retained. Interface and test changes from separate local work are excluded.
