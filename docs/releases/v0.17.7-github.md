- Фон всплывающего меню направляющих соответствует активной теме. Системная стрелка подменю больше не перекрывает тематическую.

- Обновлены описания возможностей RU/EN, контракт отрисовки и четыре изображения печатного представления с описанием их получения.
- Дополнены GUI-регрессии. Сокращены повторяющиеся проверки сочетаний клавиш и перетаскивания ползунка. Фильтровая часть потокового FRF использует меньший вход; большой вход проверки внешней сортировки сохранён. Число утверждений не является числом независимых сценариев.

## English

This release improves menus, the point-placement cursor and grayscale curve presentation. It includes the interface, test and documentation changes committed after v0.17.6.

### Changes

- The guide-line popup background follows the active theme. The native submenu arrow no longer overlaps the themed arrow.
- FRF role checkmarks are 16 px and vertically centered in their rows.
- The point-placement cursor changes contrast with the theme. Its default, reset and fallback size is 21 px; valid saved user sizes are retained.
- Grayscale curve identification uses symbols while graph paths and legend samples remain solid.
- Updated RU/EN feature descriptions, the rendering contract and four print-view images with capture provenance.
- Extended GUI regression coverage. Reduced repeated shortcut and slider-drag assertions. The streaming FRF filter fixture is smaller; the external-sort test retains its large input. Assertion counts are not counts of independent scenarios.
- Agent instructions now match the current documentation structure.

### Distribution

GitHub assets contain only AMSignal-0.17.7-x64.exe and SHA256SUMS.txt for that executable. Sources are available through the tag and GitHub Source code archives. Existing tags and assets are retained. License: GNU GPLv3.

Executables are unsigned. No new benchmarks, large-recording tests or speedup guarantees are claimed. Current test scope remains up to 10,000,000,000 bytes inclusive; this is not a hard file-opening limit. Existing RAM, disk-backed processing and analysis limitations remain.
