# AMSignal v0.17.3 — 2026-10-16

## Русский

Выпуск Windows x64 содержит накопленные изменения интерфейса и управления
после v0.17.2. Старые теги и пакеты не заменяются. Основные изменения относятся
к правой панели, выделению участка анализа, разметке, фильтру и настройкам ресурсов.

### Правая панель и видимый диапазон

- Во всех трёх режимах используется один блок «Видимый диапазон» с полями
  «От» / «До» и кнопкой «Показать диапазон». Он расположен под списком и
  настройками каналов; на вкладке «Точки» — под настройками групп. В Signal
  используются исходные секунды, в FFT и АЧХ — герцы. Enter применяет ввод.
- Изменение видимого диапазона управляет просмотром, не выбирает участок
  анализа, не запускает повторный FFT/FRF и не создаёт Undo разметки.
  Проверяются конечность, порядок и допустимые границы; сохраняются DC/Nyquist
  FFT и положительная нижняя частота АЧХ. Поля FFT/FRF отключены до результата
  и во время расчёта. Незавершённый ввод сохраняется при обновлении статуса.
- Отдельные старые поля диапазона АЧХ удалены. Её настройки и общий блок
  прокручиваются вместе; содержимое не перекрывает вкладки в небольшом окне.
- Исправлены наложения названий каналов, коэффициентов, формул и полей диапазона.
  Окончательные позиции и видимость определяются одним layout; элементы не
  показываются в старых местах, а прокрутка учитывает новую высоту содержимого.
  После смены режима/вкладки и обновления настроек не остаются старые рамки.
- При открытии АЧХ без выбранных опор или откликов раскрываются «Каналы».
  При заполненных ролях выбранная вкладка и видимость панели сохраняются.
- Убраны лишняя поясняющая подсказка АЧХ и пустая строка «Hann · L/K/Δf: —».
  Статус расчёта и параметры готовой АЧХ остаются доступны.

### Выделенный участок анализа и навигация

- Рабочий интервал сохраняет исходные фон, сетку и кривые без синей тонировки.
  Исключённые области обозначаются нейтральной диагональной штриховкой и лёгким
  затемнением; сетка и данные снаружи остаются различимыми. При zoom внутрь
  участка его пиксели не меняются, даже если границы за пределами окна.
- Сплошные контрастные границы со светлой обводкой имеют увеличенные ручки
  сверху и снизу. Наведение усиливает линию, курсор показывает перетаскивание.
  Настоящая невидимая граница не создаёт ложную ручку на краю viewport.
- Границы можно перемещать без Shift, в том числе в режиме точек и при замке
  разметки. Выбранный инструмент линии/маркера сохраняет приоритет. Во время
  движения отображается preview; отпускание применяет одну запись Undo/Redo.
  Escape, ПКМ, потеря capture и смена документа отменяют незавершённое движение.
- С включённым магнитом перемещаемая граница привязывается к ближайшему по X/Y
  исходному отсчёту видимой кривой. Для дискового обзора выполняется отменяемый
  асинхронный поиск исходного значения; экстремум обзорного bucket не заменяет
  отсчёт. Учитываются обработанные кривые, скрытые каналы и склеенная ось.
  Отмена финального запроса не применяет устаревшую границу.
- Над графиком показаны начало, конец и длительность участка, включая preview
  и границы за экраном. При скрытии разрывов подпись указывает исходное время.
  Длинная подпись не перекрывает имя оси или кривые.
- Исправлены Shift+колесо и горизонтальное колесо: перемещение учитывает
  модификатор сообщения Windows и работает для обычной/склеенной оси и АЧХ.
- В режиме точек АЧХ снова можно панорамировать и масштабировать по высоте
  нижний график средней опоры; жест навигации не создаёт лишнюю точку.

### Разметка, курсор и общие инструменты

- Магнит вынесен из «Точек» в общую кнопку для точек, линий и маркеров.
  Используется монохромная горизонтальная иконка. Группы «Курсор / Точки»,
  «Маркер / Линия», «Магнит / Замок» разделены увеличенными промежутками.
- Прицел постановки сохраняет тонкие линии и более заметную центральную точку.
  Под настройками клавиш можно выбрать размер 17/21/25/31/41/49/63 px;
  по умолчанию 31 px. Размер сохраняется как настройка приложения.
- Для текущего маркера после постановки, выбора или наведения показывается
  одна компактная карточка координат: t/Y, f/A или f/|H| с единицами.
  Координаты берутся из сохранённого маркера без повторного чтения записи.
  Карточка удерживается внутри графика, не загромождает шкалы и скрывается
  крестиком либо через «Вид → Значения маркеров». Выбор сохраняется в настройках,
  проекте и истории документа. При склейке время помечается как исходное.
- Линии маркера продолжают отображаться независимо по каждой видимой координате,
  когда его пересечение уходит за пределы графика.
- Два режима точных линий объединены в тематическое окно «Задать линию (точно)»:
  вертикальное/горизонтальное направление и числовое значение в одном диалоге.
- Уточнены RU/EN подписи разрывов: «Скрывать разрывы времени» относится к оси
  документа, «Отмечать разрывы времени» — к общей настройке приложения.
  Показ маркеров разрывов един для всех файлов, сохраняется в INI и не меняется
  при переключении документов; старый проект не подменяет эту общую настройку.

### Фильтр и перерисовка ползунков

- Ползунки нижней/верхней частот оформлены в палитре приложения с поддержкой
  обеих тем, фокуса и отключённого состояния. Native геометрия и ввод сохранены.
- При пересечении границ сохраняется именно редактируемая частота, а другая
  граница подстраивается к ней. Обе подписи/позиции согласованы в preview;
  возврат после пересечения восстанавливает нетронутую исходную границу.
- Исправлено исчезновение дорожки и бегунка после выбора частоты. Полный
  renderer не зависит от отдельных native callbacks закэшированных частей.
- Исправлены синие следы при резком движении с удержанием. Ползунок владеет
  WM_PAINT/WM_PRINTCLIENT, рисует полный кадр через буфер и завершает каждый
  drag-event синхронной перерисовкой, включая связанную границу. Результат не
  откладывается до отпускания. Preview не применяет фильтр и не добавляет Undo.

### Память и дисковый кэш

- Неясный «Автолимит памяти» заменён отдельными настройками RAM и диска.
  «RAM: автоматически» не вводит фиксированный потолок данных, но учитывает
  свободную RAM/commit и резерв системы. Ручной бюджет: 64–65536 MiB.
- Квота общего дискового кэша задаётся отдельно: 64–1048576 MiB, по умолчанию
  2048 MiB, либо «Кэш диска: без лимита». Сохраняется предел 256 записей.
  Исходные файлы и отдельные временные FFT/FRF workspace этой квотой не ограничены.
- Активные lease не удаляются; уменьшение квоты ниже занятого ими размера
  отклоняется. Параметры сохраняются в INI. Это не лимит всей памяти процесса.

### Горячие клавиши

Основные режимы: **S — Сигнал, F — FFT, R — АЧХ**. Прежние стандартные T и
Ctrl+R мигрируют в S и R только при отсутствии конфликта. Пользовательские
назначения и явно снятые сочетания сохраняются; новый конфликтующий default
остаётся неназначенным. Все новые команды доступны в настройках и справке F1.

| Команда | По умолчанию |
|---|---|
| Курсор / навигация | N |
| Магнит / замок разметки | G / L |
| Точная линия | Shift+L |
| Показать / скрыть правую панель | B |
| Каналы / Точки / Фильтр | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| Включить фильтр / скрывать разрывы времени | Shift+F / Shift+G |
| Значения маркеров / легенда / фигуры кривых | Shift+M / Ctrl+Shift+L / Shift+C |
| Участок анализа / видимый участок / вся запись | Ctrl+I / Ctrl+Shift+I / Ctrl+Alt+I |

Команда вкладки раскрывает скрытую панель. Клавиатурные команды фильтра и
разрывов принимают уведомления акселераторов; ввод в Edit/ComboBox защищён
от срабатывания команд графика.

### Проверки и границы выпуска

- Перед выпуском прошли **8601 GUI-проверка**, связанные с production-модулями.
  Проверены реальные контролы панели, RU/EN, обе темы, пиксели рабочего участка,
  магнит resident/disk, отмена и история, ввод диапазона, миграция клавиш,
  четыре режима фильтра и резкие движения обоих бегунков при удержании capture.
- Полные штатные CLI/GUI собираются из чистого нового тега с версией 0.17.3;
  версия EXE и SHA-256 проверяются перед упаковкой. Старые исполняемые файлы
  и пакеты не перезаписываются. Подробности модулей обновлены в ARCHITECTURE.md
  и AGENTS.md, включая актуальные ссылки на внешние материалы статьи/отчёты.
- FFT/H1/Welch/coherence и алгоритмы чтения не переписывались. Исправление
  пересечения частот меняет выбор параметров, а не математический метод фильтра.
  Новых сравнений производительности, испытаний 10 GB/физического ПК 8 GiB/
  FAMOS нет; задачи и новые проверки 20 GB исключены. Известные ограничения
  памяти и disk-регрессии v0.17.2 этим выпуском не объявляются устранёнными.
- Подключение SignPath Foundation по имеющимся данным ожидается. Локальные
  EXE не подписаны; локальный тег и пакет не означают публикацию GitHub Release.

## English

This Windows x64 release collects the interface and interaction changes after
v0.17.2. Existing tags and packages are preserved. The main changes concern the
side panel, analysis interval, annotations, filter controls and resource settings.

### Side panel and visible range

- All three modes share one **Visible range** block with From/To fields and a
  Show range button. It sits below the channel list/settings and below group
  settings on the Points tab. Signal uses original seconds; FFT and FRF use Hz.
  Enter applies the fields. The old separate FRF range controls are removed.
- Range changes affect the viewport, preserve the analysis selection and
  computed FFT/FRF data, and add no annotation history. Validation checks finite,
  ordered, available endpoints, including FFT DC/Nyquist and positive FRF limits.
  FFT/FRF fields are disabled without a ready result or while calculation is
  pending. Status updates preserve unfinished edits.
- FRF settings and the shared block scroll together and remain below the tabs
  in short windows. One layout owns final geometry/visibility, fixing overlapping
  channel names, multipliers, formulas, stale frames and incorrect scroll offsets
  after mode/tab changes or settings refreshes.
- Opening FRF with missing References or Responses reveals Channels. With both
  roles populated, the current panel tab and visibility are retained. Redundant
  explanatory text and the empty Hann/L/K/Δf placeholder are removed; calculated
  parameters and progress remain available.

### Analysis interval and navigation

- The working interval retains its original background, grid and traces without
  blue tint. Excluded areas use neutral diagonal hatching and slight darkening;
  their grid/data remain visible. Zooming inside the interval leaves its pixels
  unchanged even with both boundaries offscreen.
- Solid high-contrast boundaries have light outlines and larger top/bottom grips.
  Hover strengthens the line and indicates dragging. Offscreen boundaries create
  no false grips at viewport edges.
- Drag either boundary without Shift, including Points mode and annotation lock.
  An explicitly armed line/marker tool retains priority. Dragging previews the
  range; release creates one Undo/Redo change. Escape, right-click, capture loss
  or document changes cancel unfinished movement.
- With Magnet enabled, a dragged boundary snaps to an original sample on the
  nearest visible trace in screen X/Y. Disk overview uses cancellable asynchronous
  original-sample lookup rather than an overview-bucket extremum. Processing,
  hidden channels and stitched time are respected; cancelled/stale final requests
  cannot apply a boundary.
- The row above the chart shows interval endpoints and duration during preview
  and with offscreen boundaries. Stitched axes identify original time. Long text
  does not overlap axis names or traces.
- Shift+wheel and horizontal-wheel panning honor Windows message modifiers on
  normal/stitched time axes and FRF. In FRF Points mode, the lower mean-reference
  graph again supports independent vertical navigation without placing a point.

### Annotations, cursor and shared tools

- Magnet is a shared toolbar button for points, lines and markers, with a
  horizontal monochrome icon. Cursor/Points, Marker/Line and Magnet/Lock groups
  have wider separation.
- The placement crosshair has thin arms and a more visible center. Its size is
  configurable below hotkey settings: 17/21/25/31/41/49/63 px, default 31 px,
  persisted as an application setting.
- A placed, selected or hovered marker shows one compact coordinate card:
  t/Y, f/A or f/|H| with units. It reads stored marker values without rereading
  the recording, stays inside the plot and avoids cluttering scales. Close it
  with its button or View → Marker values. Visibility is retained in settings,
  projects and document history; stitched time is identified as original time.
- Marker guide lines remain visible independently on each visible coordinate
  when their intersection moves offscreen.
- Exact vertical/horizontal line commands share one themed Set line (exact)
  dialog with direction and numeric value.
- Hide time gaps describes the document axis; Mark time gaps describes the
  application-wide gap-marker setting. The latter is shared by all files,
  persists in INI and cannot be overridden by switching documents or old projects.

### Filter controls and slider rendering

- Cutoff sliders follow the application palette in both themes, including focus
  and disabled states, while retaining native geometry and input behavior.
- Crossing cutoffs preserves the value being edited and adjusts the opposite
  bound. Both preview values/positions stay consistent; retreating from a crossing
  restores the untouched original bound.
- Channel/thumb disappearance after choosing a cutoff is fixed: the complete
  renderer no longer depends on separate callbacks for cached native items.
- Blue remnants during abrupt movement with the mouse held are fixed. The
  slider owns WM_PAINT/WM_PRINTCLIENT, buffers a full frame and synchronously
  repaints after each drag event, including a coupled-bound update. Cleanup does
  not wait for release; preview still applies no filtering or Undo change.

### RAM and disk cache

- Separate RAM and disk settings replace the ambiguous automatic memory limit.
  Automatic RAM has no fixed data ceiling, while retaining free-RAM/commit and
  system-reserve checks. Manual data budgets span 64–65536 MiB.
- The shared disk-cache quota is independent: 64–1048576 MiB, default 2048 MiB,
  or unlimited. The 256-entry limit remains. Original files and separate temporary
  FFT/FRF workspaces are outside this quota.
- Active leases are retained; reducing the quota below their pinned size is
  rejected. Settings persist in INI. Data admission is not a process-wide RAM cap.

### Keyboard shortcuts

The main modes use **S — Signal, F — FFT, R — FRF**. Former default T/Ctrl+R
migrate only when S/R are free. Custom assignments and explicitly cleared keys
are preserved; conflicting new defaults remain unassigned. Settings and F1 list
all new commands.

| Command | Default |
|---|---|
| Cursor/navigation | N |
| Magnet / annotation lock | G / L |
| Exact line | Shift+L |
| Show/hide side panel | B |
| Channels / Points / Filter | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| Enable filter / hide time gaps | Shift+F / Shift+G |
| Marker values / legend / curve symbols | Shift+M / Ctrl+Shift+L / Shift+C |
| Analysis interval / visible interval / entire recording | Ctrl+I / Ctrl+Shift+I / Ctrl+Alt+I |

Tab commands reveal a hidden panel. Filter/gap commands accept accelerator
notifications; Edit/ComboBox input remains protected from chart shortcuts.

### Validation and release limits

- **8601 production-linked GUI checks** passed before release, covering real
  controls, RU/EN, both themes, working-interval pixels, resident/disk snapping,
  cancellation/history, range input, shortcut migration, four filter modes and
  abrupt held drags of both sliders.
- Standard full CLI/GUI builds use the clean new tag and version 0.17.3; EXE
  metadata and SHA-256 are checked before packaging. Older executables/packages
  are preserved. Architecture/working instructions include current module maps
  and links to externally organized article/report materials.
- FFT/H1/Welch/coherence and parsing algorithms were not rewritten. Cutoff-crossing
  fixes change parameter selection, not the filter's mathematical method. There
  are no new performance comparisons, 10 GB/physical 8 GiB/FAMOS trials or new
  20 GB work. Known v0.17.2 memory limits and disk regressions are not claimed fixed.
- SignPath Foundation onboarding was still pending in the available project
  records. Local executables are unsigned; a local tag/package does not imply a
  published GitHub Release.
