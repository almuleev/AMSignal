## Reproduce the images / Повторить изображения

Use the [demo recipe](../../examples/README.md), clean local settings and the parameters in the [manifest](screenshots/README.md). Use actual application drawing and exports; do not generate UI pixels or retouch numerical curves. Both languages show the same source, calculations and scenes.

Используйте [рецепт примера](../../examples/README_RU.md), чистые локальные настройки и параметры из [описания](screenshots/README.md). Применяйте настоящую отрисовку и экспорт приложения; не генерируйте интерфейс и не ретушируйте численные кривые. В двух языках показаны одинаковые данные, расчёты и сцены.
