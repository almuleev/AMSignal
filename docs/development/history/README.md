Не читай оба снимка целиком по умолчанию. Сначала найди нужную тему через
`rg -n` в одном файле, затем открой ограниченный участок. Например:

```powershell
rg -n '^### .*FFT|^### .*ресурс|^### .*фильтр' docs/development/history/ARCHITECTURE_NOTES_2026-10-16.md
```

Карта тем: открытие/RAM/диск, FilterStream/continuation, H1/Welch, Snap,
поколения worker, панели/горячие клавиши, внешние сравнения и выпуски.
Проверяй действующее поведение по коду и текущим контрактам; найденный старый
протокол не означает необходимость повторять тот же прогон.
Новые рабочие правила и архитектурные сведения обновляй в текущих справочниках,
новые результаты выпуска — в release notes; эти снимки остаются неизменными.
