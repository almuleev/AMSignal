# Переносимое рабочее окружение

[Документация](README_RU.md) · [English](PORTABLE_EN.md)

AMSignal запускается как самостоятельный Windows EXE: установщик, Qt и установленный LabVIEW не требуются. Настройки хранятся в `AMS.ini` рядом с приложением, а проект `.AMSig` содержит исходные отсчёты и поддерживаемые настройки анализа и разметки.

## Что перенести

| Файл | Зачем |
| --- | --- |
| `AMSignal-<версия>-x64.exe` | Приложение |
| `AMS.ini` рядом с EXE | Язык, тема, клавиши и локальные предпочтения |
| Ваши `.AMSig` | Исходные отсчёты, обработка и восстанавливаемое состояние документов |
| CSV FRF и описание опыта | Роли опор/откликов, метод, L и сохранённые результаты расчёта |
| Исходные LVM/TXT/CSV при необходимости | Архив первичных измерений и работа без проекта |

## Как продолжить на другом компьютере

1. Сохраните открытые документы как `.AMSig` и закройте приложение, чтобы локальные настройки были записаны.
2. Скопируйте EXE, `AMS.ini` и нужные проекты в доступную для записи папку на другом компьютере Windows x64.
3. Запустите EXE из новой папки. Откройте проект через **Открыть**.
4. Проверьте единицы, обработку и участок. Для нового расчёта FRF восстановите роли, метод и L по описанию опыта или CSV.

Проект содержит данные и не требует исходного LVM/TXT/CSV для чтения сохранённых отсчётов. Роли FRF, метод и L не входят в сохраняемое состояние проекта: проект и CSV результата решают разные задачи. Список недавних файлов может содержать прежние абсолютные пути; открывайте перенесённые проекты из новой папки.

## Настройки, кэш и Windows

Папке программы нужна запись для сохранения `AMS.ini`. Используйте собственную рабочую папку, если системный каталог защищён от записи.

Индексы и кэши, а также временные файлы расчёта могут находиться вне папки EXE. Их не нужно переносить для продолжения работы: они создаются заново и требуют свободного диска. Кэш не заменяет исходник или сохранённый проект.

При запуске AMSignal регистрирует ассоциацию `.AMSig` для текущего пользователя Windows без прав администратора. После перемещения запустите EXE из новой папки; системный выбор приложения по умолчанию остаётся под управлением Windows.
