# Быстрый старт

## Скачать и открыть

1. Откройте [последний выпуск](https://github.com/almuleev/AMSignal/releases/latest).
2. Скачайте `AMSignal-<версия>-x64.exe`. Архивы **Source code** предназначены для сборки, это не готовый комплект программы.
3. Запустите EXE. Выберите русский или английский язык и светлую или тёмную тему.
4. Нажмите **Открыть файл…** или перетащите запись в окно. Поддерживаются `.lvm`, `.txt`, `.csv` и `.AMSig`.

Установка LabVIEW и Qt не требуется. GUI переносимый: записывает `AMS.ini` рядом с EXE и регистрирует `.AMSig` для текущего пользователя Windows. Для анализа может создаваться дисковый кэш. Подробнее — [поведение приложения и подпись](CODE_SIGNING.md).

Чтобы повторить скриншоты, скачайте [demo-signals.txt](https://raw.githubusercontent.com/almuleev/AMSignal/main/examples/demo-signals.txt) командой **Сохранить ссылку как**. Это [синтетический демонстрационный пример](../examples/README_RU.md).

## Посмотреть сигнал

1. Выберите **Сигнал** (`S` при стандартных сочетаниях).
2. На вкладке **Каналы** оставьте нужные кривые. Имена и цвета каналов можно менять.
3. Колесо мыши меняет масштаб, перетаскивание перемещает график. **Автомасштабирование** (`A`) подбирает Y.
4. Внизу вкладки **Каналы** задайте видимый диапазон в секундах и примените кнопкой **Показать диапазон** или Enter.
5. Включите **Магнит (привязку)** (`G`), выберите **Точки** (`P`) и щёлкните по кривой для измерения.

## Рассчитать FFT

1. В режиме сигнала выберите **Анализ → Вся запись** либо задайте **Участок**. Команда **Взять видимый участок** явно копирует текущий временной вид.
2. Оставьте видимыми каналы, которые нужно проанализировать.
3. Переключитесь в **Спектр** (`F`) и дождитесь фонового расчёта.
4. Изучайте пики с помощью видимого частотного диапазона на вкладке **Каналы**. Частотный масштаб не меняет участок анализа.

Без явно заданного участка FFT и FRF используют всю запись. Простое увеличение временного графика не выбирает входные данные расчёта.

## Рассчитать FRF

1. Откройте запись с синхронными каналами возбуждения и отклика.
2. Переключитесь в **АЧХ** (`R`). Назначьте **Опоры** и **Отклики**; роли не должны пересекаться.
3. Для примера выберите `Reference A` и `Reference B` как опоры, `Response A` / `Response B` — как отклики. При отображении парсер убирает единицы в квадратных скобках из имён каналов.
4. Начните с **H1 Welch**, `L = 0` (Auto) и запустите расчёт. Для воспроизведения галереи задайте `L = 2048`.
5. Оцените коэффициент динамичности `КД = abs(H)`, отдельный спектр средней опоры и диагностику coherence.

![Рассчитанная АЧХ с двумя опорами и двумя откликами](assets/screenshots/frf-ru.png)

*На кадре рассчитан H1 для двух откликов относительно средней из двух опор: L=2048, K=31, шаг 0,5 Гц, сглаживание выключено.*

Несколько опор усредняются до оценки передаточной функции; это не MIMO. Coherence — диагностический показатель. Перед выводами об эксперименте прочитайте [допущения анализа](ANALYSIS_RU.md).

## Сохранить и продолжить

| Задача | Команда и результат |
| --- | --- |
| Продолжить работу позже | **Сохранить проект**, `Ctrl+S`: `.AMSig` с исходными отсчётами и восстанавливаемыми настройками |
| Сохранить рисунок | **Сохранить PNG**, `Ctrl+Alt+S` |
| Выгрузить каналы или результаты | **Сохранить как**, `Ctrl+Shift+S`: назначение, формат, диапазон и каналы |

Сигнал экспортируется в CSV/TXT/LVM, спектр — в CSV/TXT, FRF — в CSV и PNG. Экспорт исходных каналов не применяет обработку. CSV/TXT со столбцом `Frequency` можно открыть как готовый спектр; CSV FRF нельзя открыть как документ FRF.
