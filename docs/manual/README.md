Актуальное руководство ведётся в Markdown, с одинаковой структурой и содержанием на двух языках:

- [Русское руководство](AMSignal_User_Manual_RU.md)
- [English manual](AMSignal_User_Manual_EN.md)

The [previous expanded Russian edition](archive/AMSignal_User_Manual_RU_0.16.1.md) is retained as history. The existing `AMSignal_User_Manual_RU.docx` and `build_manual_docx.py` also belong to that earlier print workflow: their version labels, fixed Russian text and Markdown support do not describe the current manuals. Do not use the old DOCX as current instructions or regenerate it as a current deliverable without updating and visually verifying the converter.

[Прежняя расширенная русская редакция](archive/AMSignal_User_Manual_RU_0.16.1.md) сохранена как история. Существующие `AMSignal_User_Manual_RU.docx` и `build_manual_docx.py` также относятся к прежнему печатному выпуску: версия, фиксированные русские подписи и поддержка Markdown не соответствуют актуальным руководствам. Старый DOCX не следует использовать как текущую инструкцию или пересобирать как актуальный документ без обновления и визуальной проверки конвертера.

The current GitHub presentation is delivered as Markdown and images. A new DOCX/PDF edition can be built from the stabilised bilingual sources after the GitHub content is reviewed.

Текущее оформление GitHub подготовлено в Markdown и изображениях. Новый комплект DOCX/PDF можно выпускать из согласованных двуязычных исходников после проверки содержания GitHub.
